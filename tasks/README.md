# Tasks

One file per Cline task, numbered in build order (`TASK-01.md`, `TASK-02.md`, …), based on `TEMPLATE.md`.

How to run a task:
1. Open a **new** Cline task (keeps context short and cheap).
2. Paste: `Read memory-bank/ and tasks/TASK-NN.md, then complete the task.`
3. Run the acceptance tests; review the diff; commit.
