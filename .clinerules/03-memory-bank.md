# Memory bank

At the start of every task, read these files in `memory-bank/` before editing anything:
`projectbrief.md`, `productContext.md`, `systemPatterns.md`, `techContext.md`, `activeContext.md`, `progress.md`.

At the end of every task, append one bullet each to `activeContext.md` (current focus) and `progress.md` (done / next / known issues). Never rewrite existing entries: tasks run on parallel branches and rewrites cause merge conflicts.
Keep entries short — bullet points, no prose.
